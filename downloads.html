دانلود و کلاینت‌ها

فایل نصب نسخه ۲.۶۲.۰ داخل همین سایت است و دکمه هر کارت همان فایل را می‌دهد. iOS فایل جدا ندارد و از اپ‌استور نصب می‌شود. اگر نسخه تازه‌تر روی صفحه رسمی آمده، از همان‌جا بگیرید.

نسخه دسکتاپ لازم ندارد اول دلتاچت روی گوشی نصب شده باشد.

اندروید

حداقل: اندروید ۵.۰ (Lollipop)

برای بیشتر گوشی‌ها فروشگاه یا اف‌دروید کافی است. اگر فروشگاه باز نشد، APK رسمی را مستقیم بگیرید.

دانلود APK
  • APK نسخه ۲.۶۲.۰
  • اف‌دروید
  • پلی‌استور
  • هوآوی
  • کد منبع

iOS و iPadOS

حداقل: iOS 15.6، آیفون 6s، آیپد 5 / Air 2 / Mini 4

نسخه گوشی و تبلت اپل از اپ‌استور نصب می‌شود.

صفحه رسمی دانلود
  • اپ‌استور
  • کد منبع

ویندوز

حداقل: Windows 10

نسخه فروشگاه مایکروسافت خودش به‌روز می‌شود. فایل نصب و نسخه قابل‌حمل همین‌جا هستند. نسخه قابل‌حمل هنوز آزمایشی است.

دانلود نصب‌کننده
  • فروشگاه مایکروسافت
  • Setup
  • Portable
  • کد منبع
winget install 9PJTXX7HN3PK

مک

حداقل: macOS 12 (Monterey)

با Homebrew یا اپ‌استور نصب کنید. فایل DMG نسخه ۲.۶۲.۰ هم همین‌جا است.

دانلود DMG
  • Homebrew
  • اپ‌استور
  • DMG عمومی
  • DMG اپل سیلیکون
  • کد منبع
brew install --cask deltachat

لینوکس

حداقل: Ubuntu 18.04، Fedora 29، Debian 10، یا سیستم سازگار

راه اصلی و مستقل از توزیع، Flatpak روی فلات‌هاب است. بسته deb و rpm و AppImage هم برای x86_64 و arm64 منتشر می‌شود.

دانلود AppImage
  • Flatpak
  • deb برای x86_64
  • rpm برای x86_64
  • AppImage برای x86_64
  • deb برای arm64
  • rpm برای arm64
  • AppImage برای arm64
  • کد منبع
flatpak install flathub chat.delta.desktop

آرک: pacman -S deltachat-desktop

Ubuntu Touch

حداقل: Ubuntu Touch 20.04

Delta Touch را جامعه برای Ubuntu Touch ساخته و از فروشگاه Open Store نصب می‌شود.

صفحه رسمی دانلود

KaiOS و کلاینت‌های دیگر
