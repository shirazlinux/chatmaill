مدمیل: رله دلتاچت روی سرور خودتان

مدمیل (Madmail) یک رله برای دلتاچت است که با زبان Rust نوشته شده و به‌صورت یک فایل اجرایی واحد نصب می‌شود. SMTP، IMAP، اجبار رمزنگاری، پیام فوری، TURN برای تماس و Shadowsocks برای شبکه‌های محدود همه داخل همان یک فایل است. نسخه فعلی سری v2 است. در برنامه فارسی به رله می‌گویند گذرگاه. کد و راهنما: github.com/themadorg/madmail

چه چیزی لازم است

یک سرور لینوکسی (VPS داخلی یا رایانه همیشه روشن) با IP ثابت که کاربرانش به آن دسترسی دارند؛ دامنه اختیاری است. پورت‌های ایمیل (25، 465، 587، 993) و 443، و برای گواهی Let's Encrypt پورت 80.

دریافت فایل

ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
curl -fsSL "https://github.com/themadorg/madmail/releases/latest/download/madmail-linux-${ARCH}" -o madmail
chmod +x madmail

در قطعی اینترنت، گیت‌هاب در دسترس نیست. فایل را از قبل بگیرید و روی سرور نگه دارید.

حالت ۱، فقط IP با گواهی خودامضا

این حالت برای شبکه داخلی و قطعی مناسب است.

sudo ./madmail install --simple --ip YOUR_IP --lang en
sudo systemctl enable madmail
sudo systemctl start madmail

کاربران ممکن است یک بار هشدار گواهی ببینند. گواهی را فقط برای همین سرور بپذیرند.

حالت ۲، IP با گواهی معتبر Let's Encrypt

به اینترنت و پورت 80 نیاز دارد. تمدید گواهی حدود ۶ روزه است.

sudo ./madmail install --simple --ip YOUR_IP --auto-ip-cert --acme-email you@example.com --lang en

حالت ۳، با دامنه

sudo ./madmail install --simple --domain mail.example.org --acme-email you@example.com --lang en

در همه حالت‌ها YOUR_IP را با IP سرور و نشانی‌های نمونه را با نشانی واقعی خودتان عوض کنید.

بعد از نصب

صفحه وب سرور را باز کنید؛ QR دعوت آن‌جاست. کاربران با اسکن همین QR نمایه می‌سازند یا آن را به‌عنوان رله دوم اضافه می‌کنند.

Shadowsocks

مدمیل برای شبکه‌های محدود حالت Shadowsocks دارد. راه‌اندازی آن را از راهنمای Admin & CLI مخزن بخوانید و لینک ss:// را به کاربران بدهید تا در تنظیمات ← پیشرفته ← پروکسی وارد کنند.

هشدار

گرداننده رله متن پیام‌ها را نمی‌بیند، ولی IP کاربران و زمان اتصال را می‌بیند. اگر سرور داخلی است، این داده در دسترس ارائه‌دهنده سرور هم هست. سرور را به‌روز نگه دارید. طبق خود مخزن، بیشتر کد با کمک هوش مصنوعی نوشته شده و استفاده از آن با مسئولیت خودتان است.
