# معرفی چت‌میل و دلتاچت

سایت استاتیک فارسی و راست‌به‌چپ برای معرفی چت‌میل و دلتاچت.

نشانی عمومی: [chatmaill.ir](https://chatmaill.ir/)

کد سایت تحت [GNU AGPL-3.0-or-later](COPYING) است. جاوااسکریپت آزاد است و برای LibreJS برچسب خورده. فایل نصب دلتاچت، بسته ربات و فایل xdc با پروانه خود همان پروژه‌ها هستند. فایل‌های نصب دلتاچت هر کدام بزرگ‌تر از حد گیت‌هاب و آپلود پاستا هستند و داخل مخزن نیستند. نسخه همان ۲.۶۲.۰ روی دیسک محلی در `files/deltachat/` می‌ماند.

## اجرا

`index.html` را در مرورگر باز کنید، یا از پوشه پروژه:

```sh
python3 -m http.server 8080
```

بعد بروید به `http://127.0.0.1:8080/`.

## ساختار

- `index.html` معرفی
- `how.html` ایمیل چیست و دلتاچت چطور روی آن کار می‌کند
- `guides.html` آموزش گام‌به‌گام
- `faq.html` پرسش‌های متداول
- `relays.html` رله داخل ایران که هنگام ساخت صفحه جواب داده است
- `features.html` قابلیت‌ها
- `downloads.html` دانلود و کلاینت‌ها
- `bots-apps.html` ربات و مینی‌اپ
- `sources.html` منابع
- `license.html` پروانه AGPL و جدول جاوااسکریپت آزاد
- `robots.txt` اجازه خزیدن صفحه‌ها، و بستن پوشه `files/` تا فایل نصب خزیده نشود
- `sitemap.xml` دوازده صفحه HTML با نشانی مطلق chatmaill.ir
- `404.html` صفحه خطای پیدا نشدن (از sitemap بیرون است)
- `Dockerfile` و `nginx.conf` برای اجرای ایستا روی پاستا، پورت ۸۰۸۰
- `COPYING` متن کامل AGPL-3.0
- `css/style.css` استایل مشترک
- `js/site.js` انیمیشن سبک و آکاردئون پرسش‌ها
- `assets/` نشان رسمی دلتاچت و نماگرفت کلاینت‌ها
- `files/deltachat/` فایل نصب نسخه ۲.۶۲.۰
- `files/bots/` بسته کد web2pdf، پل تلگرام و public-bots
- `files/apps/` فایل‌های xdc فروشگاه delta.sudoshz.ir/apps
- `fonts/` فونت Vazirmatn با پروانه SIL OFL (فایل `OFL.txt`)

دکمه دانلود اندروید، ویندوز، مک و لینوکس به فایل محلی نسخه ۲.۶۲.۰ می‌رود. iOS فقط از اپ‌استور نصب می‌شود. اگر نسخه تازه‌تر آمده، صفحه [delta.chat/fa/download](https://delta.chat/fa/download) را ببینید.
